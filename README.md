# BST Lab — Interactive Binary Search Tree Visualizer

An interactive educational website designed to help students understand Binary Search Trees (BSTs) through step-by-step visualizations and hands-on practice.

### Live Website

https://linchelsea6-creator.github.io/bst-visualizer/

### Features

- **BST Operations:** Visualize insertion, searching, and deletion with step-by-step explanations.
- **Algorithm Walkthroughs:** Follow each operation through highlighted nodes, pseudocode, and Java reference code.
- **Interactive Challenges:** Predict deletion outcomes by selecting nodes directly in the tree.
- **Solution Replays:** Watch how deletion works through interactive animations.
- **Personalized Feedback:** Understand why an answer is correct or incorrect.
- **Randomized Practice:** Generate new BST challenges to test your understanding.

### Technologies Used

- HTML
- CSS
- JavaScript
- SVG
- GitHub Pages

### About the Project

The goal is to make BST operations more intuitive by combining visual explanations with active learning. Rather than simply watching an algorithm run, students can make predictions, explore different cases, and understand the reasoning behind each operation.
